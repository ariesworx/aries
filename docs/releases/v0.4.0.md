# Aries v0.4.0

> Published 2026-10-09. These are the notes GitHub generated for the release,
> copied from its release page when [CHANGELOG.md](../../CHANGELOG.md)
> was added. The project was not yet named Aries: the names of the
> client, the server and the repository in them are today's
> (`aries`, `ariesd`, ariesworx/aries), and nothing else is changed.

Tested with Dolt 2.4.2. `aries upgrade` and `ariesd upgrade` verify these files; to check a manual download, see README, Install.

## What's Changed
* feature: scoped memory with recall, prime and a secrets lint by @edwardfward in https://github.com/ariesworx/aries/pull/48
* feature: prices, aries cost and the cost tool by @edwardfward in https://github.com/ariesworx/aries/pull/49
* feature: aries log hours and subscription plans with amortized cost by @edwardfward in https://github.com/ariesworx/aries/pull/51
